## Project Overview
This project fulfills all the requirements for Assignment #1 of the Web Technologies 1 course. It demonstrates fundamental knowledge of HTML5 and CSS3, including page layout structures, element styling, lists, responsive tables, interactive forms, and positioning using classic CSS floats.

### Task Breakdown:

* **Task 1: Introduction to HTML & CSS (`index.html`)**
  * Personal profile card containing an image, group details, and a brief description.
  * Application of element, class, and ID selectors (`asd.css`).
  * Ordered and unordered lists, styled links with `:hover` effects.
  * Shared navigation bar for seamless switching between tasks.

* **Task 2: Simple Webpage Layout (`task2.html`)**
  * Layout structured strictly using `<div>` elements and CSS `float` positioning (no Flexbox or Grid).
  * Includes a Header, Navigation Bar, Left Sidebar, Main Content Area, and Footer.

* **Task 3: Tribute Page (`/exercise1/index.html`)**
  * A tribute page dedicated to Albert Einstein.
  * Integrates custom Google Fonts (`Poppins` and `Inter`).
  * Features a styled profile photo, a chronological event list, scientific contributions, and links to external resources.

* **Task 4: CSS Table & Form (`task4.html`)**
  * **Table:** Displays student grades with styled headers, cell borders, `rowspan` usage, alternating row colors (`nth-child`), and a highlighted row (`.highlight-row`).
  * **Form:** A feedback form with text/email inputs, a role dropdown, radio buttons, a comment textarea, and a styled submit button.
